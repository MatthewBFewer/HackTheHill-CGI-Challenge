# HackTheHill-CGI-Challenge
crud app for handling complaints + gemini api + backwards compatible enough to run on a 3DS

limitations of 3ds web browser:

- HTML 4.01
- XHTML 1.1
- CSS 1/2.1
- some CSS3
- ECMAScript (JavaScript)
- DOM 1–3
- XMLHttpRequest
- some Canvas
It supports HTTP/HTTPS up through TLS 1.2, but it has no Flash/plugin support
